# Installation

## 1. Install the `polymarket` CLI

### macOS/Linux (Homebrew)

```bash
brew tap Polymarket/polymarket-cli https://github.com/Polymarket/polymarket-cli
brew install polymarket
```

Verify:

```bash
polymarket --help
```

## 2. Install This Codex Skill

Clone the repository into your Codex skills directory using the folder name `polymarket`:

```bash
git clone https://github.com/stat-guy/polymarket.git ~/.codex/skills/polymarket
```

## 3. Validate Files

- `~/.codex/skills/polymarket/SKILL.md`
- `~/.codex/skills/polymarket/scripts/chart.py`
